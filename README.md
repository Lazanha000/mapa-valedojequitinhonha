Desenvolvido integralmente com inteligência artificial (Claude Opus 5.5), o projeto utiliza dados oficiais do IBGE para explorar a realidade social e econômica do Vale do Jequitinhonha ao longo dos anos.

Acesse o mapa interativo, consulte indicadores e acompanhe as transformações da região. Também é possível baixar a página em alta resolução.

**Acesse:** https://lazanha000.github.io/mapa-valedojequitinhonha/
